# Assets

Example data referenced by the project page and quick smoke tests.

- `kodim23.png` — Kodak image #23 (parrots). Any RGB PNG works; pass your own
  path to `sasnet.data.ImageFitDataset`.
- `gt_dragon.xyz` — Stanford dragon as an oriented point cloud (positions +
  normals, 6 columns per line). Sourced from the FINER/BACON SDF benchmark.
